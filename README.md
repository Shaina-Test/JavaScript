## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed

### Running JavaScript Programs

```bash
cd "JS programs/Programs"
node Reverse_a_string.js
node Anagrams.js
node -1.js
```

### Running TypeScript Files

```bash
cd "JS Concepts"
npx ts-node tests/_Loops/_for_loops.ts
```
